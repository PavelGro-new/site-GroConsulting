# Исправления после Android Owner-проверки — 18.11.2026

Основа — фактически развёрнутый **ae5a741**, продолжение открытого PR #1. Main не изменяется. Изменяются только главные и валютные HTML RU/ZH, тесты и документы.

Причина проблемы заявки: одна кнопка присутствовала в HTML, но panel не имела ограничения высоты/внутренней прокрутки, body блокировался. При 360×360 кнопка находилась на y≈705–761, прокрутка panel оставалась 0. Android-клавиатура может уменьшать лишь VisualViewport, оставляя LayoutViewport прежним.

Исправление: ограничить modal реальной видимой высотой/offset через VisualViewport с fallback; прокручивать только fields; оставить **единственную исходную submit-кнопку** в отдельной видимой нижней области формы, учесть safe-area и компактную шапку. На мобильном не открывать клавиатуру автоматическим focus при открытии. Native required/consent и реальный обработчик заявок сохранены.

В валютном инструменте конвертер до исправления начинался около y=2676 на 390 px из-за 54 раскрытых валют. На мобильном он расположен первым в tool-body, ввод валют — в двух колонках, дублирующий быстрый список скрыт, длинный список выбора перенесён в native details/summary с default closed при ≤768 px. Desktop остаётся open с прежним порядком. Подпись ЦБ получила непрозрачную контрастную подложку. Источник, номиналы, формулы, дата/fallback и основной script идентичны ae5a741.

Подтверждённый владельцем стаж изменён на **22 года / 22年**. Другие сведения о компании, GRO logo, Taxcom, налоговый инструмент/формулы, backend, n8n/GRO Work не меняются. [Срез текущих старых цен и вопросы](tariff-audit-2026-11-18.md); цены требуют отдельного задания.
