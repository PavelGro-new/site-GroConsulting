## Усложняющие факторы — баллы, а не фиксированные рублёвые доплаты

| Параметр | Что сейчас заложено |
| --- | --- |
| Форма | ИП/НКО/план открытия: 0; ООО: +1 балл |
| Активность | нулевая 0, редкая +1, небольшая регулярная +2, активная +4, меняющаяся +3 |
| Система | АУСН/патент 0, УСН6% +1, УСН15% +2, ОСНО +4, неизвестна +1 |
| НДС | нет 0, УСН с НДС +3, ОСНО с НДС +4, неизвестно +1 |
| Сотрудники | нет 0, 1–2: +2, 3–5: +3, 6–10: +5, больше 10: +7 и индивидуальный расчёт |
| Первичка/платежи | сами 0, редкая помощь +1, регулярная первичка +3, платежи +5, полный контур +8 |
| Касса | ИП +0,5; ООО +1 |
| Маркетплейсы | ИП +2; ООО +3; дополнительно применяется правило ограничения/минимума Стандарт+ |
| Лизинг/кредиты | ИП +1; ООО +2 |
| Более 15 продаж/поступлений в месяц | ИП +2; ООО +3 |
| Три и более дополнительных фактора | ещё +2 балла |
| ВЭД | флаг индивидуального расчёта, отдельной фиксированной суммы нет |

Базовые пороги суммы баллов: 0–<2 → Минимальный; ≥2 → Лёгкий УСН; ≥4 → Базовый; ≥7 → Стандарт+; ≥10 → Продвинутый (для ОСНО — ОСНО-лайт); ≥13 → Премиальный; ≥17 → Полный контур. Затем действуют **приоритетные исключения**: план открытия → Старт; ВЭД/больше 10 сотрудников → индивидуально; нулевая АУСН/патент без сотрудников и НДС → Минимальный; нулевая ОСНО без сотрудников → Нулевая ОСНО; полный контур с активной/меняющейся деятельностью → индивидуально; остальные платежи/полный контур → Полный контур; ОСНО с НДС — минимум ОСНО-лайт; малодеятельная НКО — Специальный лёгкий; другие частные правила — в tariffCalcCalculateResult.

Не складывать баллы как рубли. Не подставлять сюда доплаты из другого проекта или учебного бота. Налоговый калькулятор рассчитывает налоги, а не цену бухгалтерского сопровождения; его ставки/формулы не входят в это обновление.

## Где данные дублируются

- `index.html`: tariffsData, CORRIDORS, QUESTIONS, tariffCalcCalculateResult, итоговые формы квиза и карточки.
- `zh/index.html`: самостоятельная китайская копия тех же таблиц/логики. Числа нужно обновлять согласованно, сохраняя локализованные названия.
- Карточки и квиз — **два разных набора** цен и классификаций, единой таблицы соответствия нет. Например, «Базовый» в квизе — около 25 000 ₽, а карточки содержат другие суммы для ИП/ООО. Автоматически приравнивать названия нельзя.
- Исторические `.html.html` рабочей папки и старые releases — архивы, не источник текущей production-выдачи. Обновлять исходники рабочей ветки PR, не старую main и не архивные копии.
