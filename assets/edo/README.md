# Логотип Такском

`taxcom.svg` содержит оригинальные векторные контуры знака из шапки официального сайта https://taxcom.ru/, полученные 17.11.2026 из `span[aria-label="Такском"] > svg`.

Исходный viewBox `0 0 194 24` и все path d сохранены без изменений. В исходном сайте fill=currentColor наследует `rgb(41, 98, 255)`; самостоятельному SVG задан тот же цвет `#2962ff` на корневом элементе. Шрифты, растровая перерисовка и имитация текстом не используются. SVG сохраняет пропорции при масштабировании и подходит для HiDPI.

Использование разрешено владельцем GRO Consulting в рамках партнёрских отношений с Такском. Копии прежнего SVG проекта/архива содержали обычный текст на широком холсте и не использованы как официальный знак. Контрольные суммы и тест контуров — в `taxcom-source.json` и `tests/static-regressions.mjs`.
